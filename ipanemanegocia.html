Como funciona

🔐

Proteção dos seus dados

A consulta é feita por uma camada segura de servidor. A credencial de acesso à base de dados não fica armazenada na página aberta no navegador, reduzindo o risco de exposição da chave de acesso.

Dúvidas frequentes

Antes de continuar

Por que preciso informar minha data de nascimento?

Ela é utilizada como uma segunda informação para confirmar que o CPF consultado pertence à pessoa que está realizando o atendimento.

O que acontece se a data não conferir?

A validação é recusada e nenhum dado cadastral adicional é apresentado na página.

Minha chave de consulta fica no HTML?

Não. Nesta versão, a página chama um intermediário seguro no servidor, e é esse servidor que possui a credencial para consultar a API.
